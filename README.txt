HOLOGRAM PORTFOLIO - how to run

1. Unzip the folder.
2. Easiest: double-click index.html (opens in Chrome/Edge).
   Better: open the folder in VS Code and use the "Live Server" extension,
   or run in the folder:  python -m http.server 8000
   then open http://localhost:8000
3. Edit your name, skills, projects, contact in index.html
   (search for "const D=").
4. To make the watch more or less straight, change TILT in index.html
   (search for "const TILT"). 0 = original angle, 22 = default, 30 = very straight.
5. Keep watch.png in the same folder as index.html.
